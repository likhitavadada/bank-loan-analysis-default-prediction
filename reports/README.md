# Generated reports

Run `python src/analyze_and_model.py` from the repository root to generate:
- `data_quality_summary.json`
- `descriptive_summary.csv`
- `summary_by_default_flag.csv`
- `default_rate_by_loan_purpose.csv`
- `model_metrics.json`
- `model_evaluation.txt`
- EDA charts and confusion matrices (`.png`)

Outputs are generated locally and may be committed if useful, but label them as results from synthetic data.
